多元支付機

DTS 螢幕設定與 I²C 觸控整合

接通顯示與觸控，讓裝置能被操作。

開發範圍Android 平台 DTS 螢幕設定與 I²C 觸控整合。
概況 架構 實作 驗證 成果

01 / SCOPE

嵌入式平台與整合範疇

這款 4.3 吋多元支付裝置主要提供 NFC、QR Code 與條碼等交易操作介面。工程核心聚焦於 Android 底層的硬體周邊適配，確保面板顯示正常且電容觸控靈敏。

平台環境
Rockchip 平台搭配 Android 系統
顯示整合
DTS 時序配置、背光與面板電源設定
觸控整合
I²C 匯流排通訊、中斷設定與座標映射

02 / ARCHITECTURE

顯示與觸控雙獨立路徑

系統架構中，顯示輸出與觸控輸入為兩條獨立運作的硬體路徑；DTS 為底層硬體配置描述來源，引導驅動程序完成面板時序與匯流排掛載。

路徑 A · 顯示輸出管線

DTS display-timings 時序參數配置 → SoC 顯示控制器驅動 → 4.3 吋面板時鐘與圖像訊號輸出。

路徑 B · 觸控輸入管線

電容觸控 IC 取樣 → I²C 匯流排傳輸與硬體中斷 → Linux Kernel 驅動 → Android Input 事件座標映射。

03 / IMPLEMENTATION

關鍵實作與參數調校

面板適配需依據面板規格書之時脈、前緣／後緣與同步脈寬進行設定，並在 Device Tree 中完成觸控晶片之 I²C 節點掛載。

PAY-01 實際 DTS 修改片段 顯示時序節點代碼截圖，建議比例 16:10
PAY-02 真實觸控整合／事件紀錄 getevent 輸出或座標日誌截圖，建議比例 16:10

04 / VERIFICATION

問題與驗證

顯示時序偏移排查與觸控軸向對齊是確保使用者操作順暢的基礎。

驅動適配驗證狀態 驗證紀錄待補

已確認完成 4.3 吋螢幕畫面正常顯示與觸控點擊輸入之連動流程。時序抖動排查與觸控多點映射之詳細波形或 log 紀錄待補入。

PAY-03 真實顯示／觸控修正前後對照 真實時序排查波形對照或觸控軌跡截圖，建議比例 16:10

05 / OUTCOME

接通顯示與觸控的操作介面

完成 4.3 吋多元支付機之 Android 底層 DTS 螢幕設定與 I²C 觸控整合，讓硬體裝置具備穩定顯示與即時觸控反饋，承載支付操作介面。
