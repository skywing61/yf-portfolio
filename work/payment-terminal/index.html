03 / 顯示與觸控整合

多元支付機

感應、掃碼與觸控整合。

面對多元支付與店員人力有限的自助結帳情境，使用者需要清楚找到感應、掃碼與輸入位置，店面也希望減少設備堆疊。本案以 4.3 吋觸控螢幕整合感應與掃描模組，透過底層顯示與觸控配置及緊湊機構堆疊，完成可操作的支付整合樣機，讓不同付款方式能在同一操作介面完成確認。

開發範圍Android 平台 DTS 螢幕設定、I²C 觸控整合，以及工業與機構設計。

驗證目標歷時 8 週完成實體樣機，驗證 NFC 感應、掃碼與觸控三合一零干擾堆疊與操作動線可行性。

< 15 ms 觸控中斷響應延遲
> 40 mm NFC 射頻感應距離
三合一 感應、掃碼與觸控整合

01 / ARCHITECTURE

顯示時序與觸控驅動

顯示與觸控各有獨立硬體路徑，透過 Device Tree（DTS）配置驅動及匯流排。

DTS 時序參數配置

依面板規格設定時序，配置像素時脈頻率與同步脈寬。

I²C 觸控匯流排掛載

觸控 IC 取樣座標，透過中斷訊號通知核心驅動處理。

Android Input 座標映射

將底層觸控事件映射至螢幕座標，對應操作介面的輸入位置。

架構抉擇掃描模組突發送入大量字串，與觸控事件分流處理，確保高頻刷卡與按鍵輸入零卡頓。

02 / IMPLEMENTATION

機構堆疊與走線配置

在 4.3 吋精巧機身內整合顯示觸控總成、NFC 射頻天線、掃描模組與散熱主板，兼顧緊湊堆疊與組裝便利。

多模組空間堆疊

垂直配置螢幕、掃描模組、中框與主板，壓縮整機厚度。

射頻天線與金屬淨空

規劃 NFC 天線與金屬件的安全距離，避免感應訊號受干擾。

內部走線與組裝公差

依 FPC 彎折與走線需求預留散熱空間，配合組裝流程。

03 / OUTCOME

多元支付操作樣機

完成 4.3 吋多元支付機之軟硬體整合，涵蓋 Android DTS 顯示時序、I²C 電容觸控與緊湊機構堆疊。實機樣機能執行卡片感應、條碼掃描與鍵盤輸入，提供清楚的支付互動流程。
