03 / 顯示與觸控整合

多元支付機

接通顯示與觸控，讓裝置能被操作。

開發範圍Android 平台 DTS 螢幕設定與 I²C 觸控整合。

01 / ARCHITECTURE

顯示輸出與觸控輸入雙獨立路徑。

顯示輸出與觸控輸入為兩條獨立硬體路徑，由 Device Tree（DTS）統一配置底層驅動與匯流排。

DTS 時序參數配置

依據面板規格定義 display-timings 時鐘頻率與同步脈寬參數。

I²C 觸控匯流排掛載

電容觸控 IC 取樣並透過硬體中斷通知 Linux Kernel 驅動。

Android Input 座標映射

底層 input 事件精確映射至螢幕解析度與系統介面座標。

payment-terminal-architecture.webp 建議比例 16:10

02 / IMPLEMENTATION

面板適配、機構分件與訊號調校。

在 4.3 吋精巧機身內整合螢幕、觸控、射頻天線與核心主板，排查時序偏移與軸向對齊。

時脈與時序除錯

調校前後緣時脈消除畫面抖動，確保面板背光與供電穩定運作。

觸控軸向與旋轉對齊

解決觸控採樣座標與螢幕顯示方向映射誤差，確保靈敏點擊反應。

機構走線與天線配置

整合顯示面板、觸控層、NFC 射頻天線與主板內部有限空間。
