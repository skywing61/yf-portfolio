類紙感數位畫框與 CMS

隨環境光調整的類紙畫框。

將數位畫作帶入居家與展示空間，需要兼顧觀看質感與內容更新。螢幕反光，以及與周遭光線不協調的亮度和色溫，都會影響畫作融入空間的效果。本案選用超低反光、抗眩光的螢幕表面材質，搭配環境光感測器調整色溫與亮度，共同呈現接近紙質畫作的觀感。開發從早期本機感測原型延伸至 CMS 連網版本，串接合作夥伴的平台遠端更新畫作，兼顧展示質感與日常管理需求。

開發範圍畫框端 Android App、環境光感測器硬體與韌體；串接合作夥伴的 CMS。
PoC 驗證決策摘要
🎯 驗證使命 (Goal)

驗證 27 吋超低反光抗眩光面板在不同室內光線下，「自適應色溫與亮度擬真類紙觀感」與「雲端 CMS 遠端高解析排程更新」的整合可行性。

⏱️ 交付節奏 (Speed)

從早期原型至連網驗證：主導畫框端 Android App 與感測器取樣韌體開發，並制定 API 合約串接合作夥伴雲端平台。

⚖️ 關鍵技術取捨 (Trade-offs)

環境光採樣二階平滑濾波：感測器採樣值若直通背光調整，易因行人走動陰影造成螢幕閃爍；設計軟體動態緩衝曲線，實現無感自然呼吸漸變。

🏁 驗證結論 (Outcome)

打通手機 BLE 配網、雲端畫作派送與環境光色溫自適應全鏈路，成功推進至商業銷售與展示階段。

< 1.5% 面板表面超低反射率

特殊霧面光學處理消除環境雜亂反光倒影。

100 階 色溫與亮度動態漸變

消除突發陰影干擾，呈現如紙張般的自然融合。

01 / ARCHITECTURE

雲端內容更新路徑。

系統架構由低反光顯示表面、環境感測調節與合作夥伴 CMS 內容更新三部分構成，兼顧觀看質感與遠端管理。

手機 BLE 配網

手機 App 搜尋探索畫框裝置，快速配置現場 Wi-Fi 連線與認證。

雲端 CMS 內容派送

畫框連上 CMS，自動接收高解析畫作與展示排程。

手機雲端裝置控制

手機 App 可切換播放清單、調整亮度與色溫，並控制螢幕休眠。

02 / IMPLEMENTATION

感測硬體適配。

從本機感測原型到 CMS 連網量產，整合 27 吋類紙感顯示與內容管理。

多感測器硬體整合

整合手勢、重力與環境光感測器，開發 MCU 取樣韌體。

環境光數據平滑處理

平滑處理環境光數據後送入顯示核心，讓亮度變化更平順。

環境色溫自適應

取樣環境光，透過 I²C／UART 調整畫框色溫與亮度。

架構抉擇：跨組織邊界定義與 API 合約 (API Contract)

畫框端牽涉本地 Android 顯示核心與第三方開發之雲端 CMS。為避免開發時程互相拖累，前期即主導制定標準 RESTful / WebSocket 通訊協定與狀態回報機制，將雲端派送邏輯與本地感測調光完全解耦。

03 / OUTCOME

智慧藝術畫框量產

CMS 連網版本成功推進至量產銷售階段，完成了畫框端 Android App 開發、感測器硬體與取樣韌體整合，以及由合作夥伴開發的雲端內容管理平台串接。
