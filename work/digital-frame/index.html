02 / 顯示與內容管理

類紙感數位畫框與 CMS

從環境感測到內容更新，整合畫框的軟體與感測器硬體、韌體。

開發範圍軟體系統開發、感測器硬體與韌體整合。

01 / ARCHITECTURE

雲端內容更新路徑。

系統架構由環境自適應與內容更新兩部分構成，兼顧本機光照調節與遠端排程派送。

手機 BLE 配網

手機 App 搜尋探索畫框裝置，快速配置現場 Wi-Fi 連線與認證。

雲端 CMS 內容派送

畫框連網對接 CMS 內容管理伺服器，自動接收高解析數位畫作與排程。

手機雲端裝置控制

透過手機 App 遠端切換播放清單、自訂顯示亮度與色溫，並支援螢幕休眠關閉。

02 / IMPLEMENTATION

感測硬體適配。

歷經早期本機感測原型至 CMS 連網量產版本，完成 27 吋類紙質感的系統落地。

多感測器硬體整合

整合手勢、重力方向與環境色溫感測硬體，於周邊 MCU 開發取樣韌體。

平滑無閃爍調光演算法

平滑化環境光數據傳遞至 Android 顯示核心，消除肉眼可見的亮度跳階。

環境色溫自適應

感測板即時取樣環境光線，透過 I²C / UART 介面微調 Android 顯示層色彩。

03 / OUTCOME

量產銷售的智慧藝術畫框

CMS 連網版本成功推進至量產銷售階段，完成了畫框軟體開發、感測器硬體與取樣韌體整合，以及雲端內容管理平台的串接落地。
