類紙感數位畫框與 CMS

感測自適應與雲端內容管理系統

從環境感測到內容更新，整合畫框的軟體與感測器硬體、韌體。

開發範圍軟體開發、感測器硬體與韌體整合。
概況 架構 實作 驗證 成果

01 / SCOPE

雙版本演進與職責劃分

本專案在不同發展階段對應兩種產品架構：早期感測版本專注於機身硬體感測與本機互動；CMS 連網版本則聚焦於遠端內容更新與手機連網設定，並推進至量產銷售。

早期感測版本

整合手勢、重力方向與環境色溫感測硬體，於周邊 MCU 開發取樣韌體，透過 I²C / UART 介面將環境光與姿態數據對接至 Android 顯示核心。

CMS 連網版本（量產銷售）

串接雲端 CMS 平台進行作品排程派送，並開發手機端 BLE 連網設定流程，讓裝置連上 Wi-Fi 自動更新展示內容。

02 / ARCHITECTURE

感測對接與內容更新路徑

系統架構由環境自適應與內容更新兩部分構成。感測端由感測板即時取樣環境光線傳遞給 Android 顯示層；內容端則透過手機連網設定後，由雲端 CMS 派送展示內容與排程。

01 · BLE 設定 手機探索設備並配置 Wi-Fi 連線
02 · 雲端連線 畫框連網對接 CMS 內容管理伺服器
03 · 內容更新 接收並更新高解析度數位畫作與排程
04 · 環境調適 感測器取樣環境光，自適應微調顯示

03 / IMPLEMENTATION

環境感測與連網設定實作

針對 27 吋大螢幕的類紙質感，環境光調節需保持平滑無閃爍（環境色溫調整效果見開場展示）；同時在使用者端，提供簡潔的手機連網配置介面。

FR-01 感測板與通訊整合（標註所屬版本） 感測板硬體、接線介面與通訊標示，建議比例 4:3

04 / VERIFICATION

問題與驗證

感測數據傳輸平滑度與遠端連網更新流程為整合測試之重點。

感測與更新驗證狀態 驗證紀錄待補

已確認完成早期感測版本之環境光取樣顯示連動，以及 CMS 連網版本之配網與內容派送。不同光源下的感測數據平滑度與網路重試紀錄待補入。

FR-02 感測資料與顯示對照紀錄 真實驗證紀錄待補：實際數據 log、光照對照或排查紀錄，建議比例 16:10

05 / OUTCOME

量產銷售的智慧藝術畫框

CMS 連網版本成功推進至量產銷售階段，完成了畫框軟體開發、感測器硬體與取樣韌體整合，以及雲端內容管理平台的串接落地。
