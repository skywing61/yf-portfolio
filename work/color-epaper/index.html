01 / 整案開發

彩色電子紙桌面立牌

低功耗無線顯示與軟硬體整合

讓桌面的展示內容，可以透過手機隨時更新。

開發範圍PCB 電路與布局、MCU 韌體、Android App、工業與機構設計。
概況 架構 實作 驗證 成果

01 / SCOPE

整案開發範圍

這款 7.3 吋彩色電子紙桌面立牌提供手機更新展示內容的流程。工程實作橫跨電路、韌體、應用與機構，把產品從板件和狀態流程串接成完整可操作的展示物件。

硬體配置
PCB 電路與布局、電池供電、FPC 走線、機構支架
MCU 韌體
ESP32-S3、BLE 配網、Wi-Fi 傳輸、閒置深眠控制
軟體與機構
Android App 傳圖應用、操作介面與外觀機構設計

02 / ARCHITECTURE

設定、更新與待機流程

首次設定、圖片更新與閒置待機分成不同工作狀態。BLE 讓手機找到裝置並設定 Wi-Fi；連網後回傳狀態並接收圖片；五分鐘無訊息後自動進入深眠省電。

01 · BLE 設定 手機探索立牌並配置現場 Wi-Fi 連線
02 · Wi-Fi 更新 裝置連上網路，接收手機傳送之影像
03 · 顯示更新 彩色電子紙刷新畫面並常駐保持顯示
04 · 閒置深眠 傳圖結束五分鐘無操作自動進入深眠

03 / IMPLEMENTATION

電路與機構一體配置

立牌需要在方便更新與電池使用之間取得平衡。FPC 的接出位置、電池與按鍵空間共同影響布局；天線放在產品邊緣，前側 LED 配置在 PCB 的另一面，讓狀態提示能從產品正面清楚辨識。

韌體與 App 流程

分開處理 BLE 設定、Wi-Fi 圖片更新與閒置深眠，讓手機 App 能依裝置當前連線狀態順暢推進傳圖步驟。

PCB 與機構整合

依 FPC 接出位置、電池厚度、邊緣 I/O 接孔、天線與 LED 位置安排電路板件與支架結構。

EP-01 主板原理圖與 PCB 布局 原始電路圖匯出或局部布線圖，建議比例 16:10

04 / VERIFICATION

問題與驗證

整案開發涉及無線連線、影像傳輸與省電模式切換，各階段驗證以實機流程排查為依歸。

實機驗證狀態 驗證紀錄待補

已確認完成 BLE 配網、Wi-Fi 傳圖與五分鐘無訊息深眠之實機操作流程。配網重試、傳輸容錯與深眠喚醒之詳細測試日誌待補入。

EP-02 真實韌體／硬體排查紀錄 對應實際問題之排查 log、波形截圖或對照紀錄，建議比例 16:10

05 / OUTCOME

可更新的桌面展示產品

交付範圍涵蓋電路硬體、MCU 韌體、Android App 與外觀機構，完成一套可實際操作、由手機端更新顯示內容的彩色電子紙桌面產品。
