05 / 跨端互動

多人多視角裸視 3D

以 PyQt、Web Three.js 與 GCP 上的 Node.js，完成跨端互動展示。

開發範圍PyQt、Web Three.js，以及 GCP 上的 Node.js 軟體開發。
概況 架構 實作 驗證 成果

01 / SCOPE

跨端分工與模組劃分

本系統將 3D 模型管理、裸視 3D 渲染與觀眾手機端互動整合成展場展示方案。軟體實作聚焦跨端核心模組：桌面端校準管理工具（PyQt）、前端 Web 視差渲染（Three.js），以及雲端模型管理與通訊服務（Node.js on GCP）。

桌面端
PyQt · 播放校準與管理控制
Web 渲染端
Three.js · 即時視差與多視圖呈現
雲端服務端
Node.js on GCP · 3D 模型與通訊分發

02 / ARCHITECTURE

跨端資料流與操作流程

管理者透過後台管理 3D 模型資源；現場主機載入模型並調用渲染器；觀眾以手機掃描專屬 QR Code 開啟 Web 操作介面，即時傳遞旋轉、縮放與展品切換等操作指令，螢幕同步呈現立體畫面。

01 · 模型管理 3D 模型託管於雲端儲存庫
02 · 桌面載入 PyQt 管理並調校光學參數
03 · 手機操作 觀眾連線發送視角控制指令
04 · 視差渲染 Three.js 即時運算立體多視圖
3D-01 已確認的跨端分工架構圖 桌面、Web 與雲端模組分工與指令關聯圖，建議比例 16:10

03 / IMPLEMENTATION

Three.js 視差渲染與雲端模型管理

前端渲染需兼顧光柵視差計算與行動端手勢的即時響應（操作介面對照見開場展示），雲端服務則負責模型資源分發與操作同步。

04 / VERIFICATION

問題與驗證

跨端互動系統的整合重點在於維持展場環境下的操作響應流暢度與渲染穩定性。
